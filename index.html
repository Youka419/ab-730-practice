中間レベルの基礎知識編 ＋ 公式模擬への入口

学習ダッシュボード

ここにある問題はオリジナルの基礎知識編です。公式模擬よりやさしく、単なる用語暗記より難しい、その中間です。本番に近い言い回しは、下の公式模擬から Microsoft Learn で確認してください。

公式模擬

Microsoft Learn の Practice Assessment

公式模擬を開く 別ウィンドウ Microsoft アカウントでログインして、公式の練習問題を受験します。問題はこのアプリには取り込みません。成績も公式サイト側に残ります。

公式模擬の問題文の転載はできません。公式はシナリオと「似た Copilot 操作」の区別が細かいです。反復練習は下の基礎知識編（中間レベル）、仕上げは公式サイト、と使い分けてください。

基礎知識編（中間レベル）

オリジナル 150 問。業務シナリオと近い誤答

基礎知識編は公式試験の再現ではありません。誤答は「あり得ない操作」ではなく、実際に Copilot でできる近い操作を置いています。合格点 700/1000 は簡易換算（正答率 × 1000）です。

ヘルプ — 使い方

基礎知識編は 3 分野それぞれ 50 問、合計 150 問の中間レベルです。公式模擬は Microsoft Learn で別途受験します。

公式模擬 最初に 出題の種類 解き方 結果のあと ホームの数字 おすすめの進め方

公式模擬と基礎知識編

  • 公式模擬 … ホームのボタンから Microsoft Learn の Practice Assessment を開きます。Microsoft アカウントが必要です。問題はこのアプリにはありません。言い回しと誤答の近さは公式の方が本番に近いです。
  • 基礎知識編 … このアプリのオリジナル 150 問（中間レベル）です。業務シナリオを読み、似た Copilot 操作から正しい依頼を選びます。履歴・弱点分析・続きから再開はこちらだけに残ります。

基礎知識編は、公式模擬ほど細かい言い回しは使わず、かといって「あり得ない誤答」だけの簡単問題にもしていません。正解した論点も不正解の論点も、別シナリオで同じ型（短い状況 → 依頼または機能を選ぶ → 近い誤答）で練習できます。

最初にやること

  1. 基礎知識編の 学習モード か 試験形式 を 1 回解く
  2. 結果が 履歴 に残り、分野ごとの正解率が溜まる
  3. そのあと 間違えた問題を復習 と 弱点分野を再出題 が使える
  4. 言い回しの確認は 公式模擬を開く で Microsoft Learn を使う

基礎知識編では、どのモードでも出題順と選択肢は毎回入れ替わります。

解き方

  • 選択肢をクリックして選ぶ（複数選択の問題は該当を 2 つ）
  • 解答を確認 … 学習系モードで、その場で正解と解説を見る
  • 次へ / 前へ … 問題の行き来
  • フラグ … あとで見直したい問題に印
  • 下の番号マスで、任意の問題にジャンプ
  • ホームへ で中断すると進捗が保存され、基礎知識編の全体（学習・試験形式）も分野別も続きから再開できる
  • 最後の問題で 結果を見る（試験形式は 終了して採点）

キーボード：1〜4 で選択、Enter で確認または次へ、矢印キーで前後です。

結果画面のあと

  • 今回の誤答を見直す … 解説だけ見る
  • 誤答をシャッフル再出題 … 今回間違えた問題を、選択肢を入れ替えてもう一度解く
  • 弱点分野を出題 … この回で正答率が低かった分野を集中して解く
  • 同じ条件でもう一度 … 今やったモードをもう 1 セット

結果は自動で履歴に保存されます。合格ラインは 700 点（正答率 × 1000 の簡易換算）です。

ホームで見られる数字

  • 累計正解率 / 累計回答 / 受験回数 / 未復習の誤答
  • 弱点分野の分析 … 3 分野の累計正解率。低い分野に「弱点」と出る
  • 履歴 … 日時、モード、正答率、スコア、分野ごとの内訳

記録はこの PC のこのブラウザだけに残ります。消すときは履歴の 履歴を削除 です。

おすすめの進め方

  1. まず基礎知識編の 学習モード で全体をつかむ
  2. 試験形式 で時間配分を試す
  3. 履歴で弱い分野を確認し、弱点分野を再出題
  4. 間違えた問題を復習 が 0 問になるまで繰り返す
  5. 言い回しの確認は 公式模擬を開く
  6. 直前は基礎知識編の シャッフル 20 問 か 試験形式、あわせて公式模擬

基礎知識編は公式試験の再現ではありません。出題範囲に合わせた中間レベルの練習用です。仕上げは公式模擬で言い回しを確認してください。

基礎知識編は中間レベルの学習用オリジナル問題です。出題範囲は Microsoft Learn の Exam AB-730 Study Guide（2026年7月22日時点）に準拠しています。
公式模擬は Microsoft Learn 上で受験してください。商標は各権利者に帰属します。このアプリの記録はブラウザの localStorage に保存されます。
